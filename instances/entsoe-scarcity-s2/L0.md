## 3. Raw Response, Container Handling & Multi-Document Merge Rules

1. **Raw Byte Preservation:** Every raw HTTP response payload must be preserved byte-for-byte under `evidence/runs/<RUN_ID>/raw/` before any container extraction or parsing.
2. **Batch Metadata:** Record request URL (token redacted), request timestamp $T_{\text{req}}$, response timestamp $T_{\text{resp}}$, HTTP status code, and SHA-256 digest of raw bytes in `run_metadata.json`.
3. **Transport Container & PKZip Extraction Rules (B-19 Resolution):**
   - ENTSO-E returns A85 responses encapsulated within standard PKZip compressed archives (magic bytes `50 4B 03 04` / `b'PK\x03\x04'`).
   - If the raw payload starts with PKZip magic bytes:
     - Open archive in memory using `zipfile.ZipFile`.
     - Extract all member filenames and sort them strictly alphabetically (`sorted(zip_ref.namelist())`) for deterministic processing.
     - Record an inventory entry for every member file (member filename, uncompressed size, member SHA-256 digest).
   - If the raw payload starts with direct XML (`b'<'`), parse directly.
   - If the raw payload is neither a valid PKZip archive nor valid XML, halt immediately with `PAYLOAD_FORMAT_UNEXPECTED`.
4. **Multi-Document & Revision Merge Rules:**
   - For every extracted `Balancing_MarketDocument` XML document:
     - Verify `documentType = A85` and `<process.processType>A16</process.processType>`. (Failure $\rightarrow$ `SOURCE_IDENTITY_INVALID`).
     - Verify `<resolution>PT15M</resolution>` for all contained time intervals. (Failure $\rightarrow$ `SOURCE_IDENTITY_INVALID`).
     - For repeated `mRID` document revisions, identify the numerically latest `revisionNumber` as the current-state document while preserving all received revisions in the inventory.
     - Extract all 15-minute point observations (`position`, `imbalance_Price.amount`, `direction`).
     - Map observations across all members into the unified chronological UTC series.
     - Any duplicate observation on the same registered UTC MTU with conflicting values or unresolvable revision conflicts is an immediate Target S failure. Zero analyst-discretion deduplication.
